# From-Scratch Cryptography

A collection of cryptography, hashing, and Bitcoin/Ethereum utilities implemented from scratch in modern C++.

Each link goes to its own repository under [github.com/cartercpp](https://github.com/cartercpp).

Companion indexes: [ml-from-scratch](https://github.com/cartercpp/ml-from-scratch) · [data-structures](https://github.com/cartercpp/data-structures) · [algorithms-from-scratch](https://github.com/cartercpp/algorithms-from-scratch) · [systems-from-scratch](https://github.com/cartercpp/systems-from-scratch) · [simulations-and-visuals](https://github.com/cartercpp/simulations-and-visuals) · [compile-time-cpp](https://github.com/cartercpp/compile-time-cpp)

## Notes

- Implementations are standalone C++ projects (typically C++20/C++23).
- This repo is an index. The code lives in the linked repositories.
- Near-duplicate wrappers (consoles, microservices, one-off SHA/BTC demos) are omitted in favor of the strongest implementation of each idea.
